# 2. Glossary

  -----------------------------------------------------------------------
  Term                    Definition
  ----------------------- -----------------------------------------------
  Curriculum              Fixed educational content authored by
                          educators.

  Dynamic Roadmap         Personalized learning journey generated by the
                          engine.

  Learning Event          Immutable record of a learner interaction.

  Learning Evidence       Normalized facts derived from learning events.

  Metric Snapshot         Derived metrics calculated from evidence.

  Learner State           Current educational projection of the learner.

  Learning Debt           Unresolved learning requiring additional
                          practice.

  Daily Practice          Review of stable topics before new learning.

  Mastery Practice        Practice scheduled to resolve learning debt.

  Reinforcement           Scheduled review to strengthen long-term
                          retention.

  Recovery Mode           Temporary adaptation to reduce cognitive load
                          after sustained struggle.
  -----------------------------------------------------------------------

# 14. Frequently Asked Questions

**Does the curriculum change?**

No. Only the roadmap changes.

**Can evidence be edited?**

No. Evidence is immutable.

**Can learner state be rebuilt?**

Yes, from historical events and evidence.

**Does the frontend make adaptive decisions?**

No. All adaptive logic resides in the backend.

**Is ML required?**

No. Version 1 is fully rule-based.

------------------------------------------------------------------------

# 15. Final Principles

The Adaptive Learning Engine is built on these principles:

-   Observe before deciding.
-   Evidence before labels.
-   Curriculum is static.
-   Roadmap is dynamic.
-   Adapt per modality.
-   Preserve learner confidence.
-   Keep decisions deterministic.
-   Make every decision explainable.
-   Protect learner data.
-   Build for long-term evolution.
